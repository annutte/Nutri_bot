# 🥦 Nutri_bot

Бот-нутрициолог в Telegram. Генерирует меню на неделю с учётом индивидуальных требований.   

- ИИ генерирует персональный план питания на неделю с учётом нормы дневных калорий (по формуле Миффлина-Сан Жеора), цели (похудеть/сохраниять форму/набрать вес), пищевых предпочтений и ограничений. 
- Ассистент ведёт диалог на естесственном языке, отвечает на вопросы, подсказывает рецепты приготовления блюд.  
- Случайный ЗОЖ-рецепт из базы – для вдохновения.  

---

## 🔍 Функционал
- Удобная система навигации  
- Анкета пользователя в виде Telegram MiniApp 
- Генерация меню на неделю с учётом индивидуальных параметров  
- Проверка даты генерации, новое меню каждую неделю  
- Возможность диалога с ИИ в свободной форме  
- Интеграция с базой данных (запись меню, запись диалогов, LightCRM)  

---

## 🎯 Для кого этот бот
- Нутрициологи и диетологи – автоматизация расчётов и освобождение времени специалиста для консультаций.   
- Фитнес-клубы – меню под цели тренировок. Подписка на бота как бонус для клиентов.  
- Медцентры, wellness-клиники – персональное питание до и после процедур. 
- Сервисы доставки еды и магазины ЗОЖ – рекомендации блюд и список покупок по КБЖУ – рост среднего чека и повторных заказов.  
- Корпоративный wellbeing – программы питания для сотрудников как демонстрация заботы со стороны компании.
